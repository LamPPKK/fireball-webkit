# fireball-webkit

F0 iOS/iPadOS 18+ foundation for the native Fireball browser shell.

The app is intentionally a thin SwiftUI shell around one `WKWebView`. WebKit remains responsible for web rendering and its sandboxed process model; Metal is not used to rerender page content.

Implemented in F0:

- one tab and bottom omnibox;
- explicit HTTP/HTTPS URL policy at omnibox and `WKNavigationDelegate` boundaries;
- regular/private profile abstraction using persistent or nonpersistent `WKWebsiteDataStore`;
- private tabs excluded from session restoration;
- `WKContentRuleList` compiler boundary and a bundled sample rule;
- Keychain and `LocalAuthentication` protocols with test fakes;
- iOS simulator build/test project generated by XcodeGen.

Multiple persistent-profile isolation, the full tab grid, rule signature distribution, biometrics UI, StoreKit and macOS remain Gate E2 work. A private/nonpersistent data store is covered now; F0 does not claim that multiple persistent profiles are isolated.

## Build and test

```sh
xcodegen generate
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  xcodebuild -project FireballWebKit.xcodeproj -scheme FireballWebKit \
  -destination 'platform=iOS Simulator,name=iPhone 16' test
```
